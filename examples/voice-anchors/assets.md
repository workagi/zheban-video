# 素材准备

这是约5秒的词语锚点接口示例，不是60秒成片美术质量样板。

- 将合法持有的 Noto Serif SC 可变字体和 OFL 许可放在 assets/fonts/，字体文件名为 NotoSerifSC-VF.ttf；fontFiles 使用本地别名 Noto Serif CJK SC。也可改为项目已有字体。
- 文本是反射定律公共知识；图形全部代码绘制，没有外部截图或图片。
- script.json 为 Edge TTS 公开示例。用户授权在线配音后执行 build.sh PROJECT tts，再 preview/full。音频、时间轴和 SRT 会自动生成；本模板不包含声音二进制文件。
- 自定义组件只保留科学镜头，实际片段、时序及全部技术报告在本次验证交付包中。
