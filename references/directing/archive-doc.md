# 档案纪实：导演规则

- 主体：原始材料、事件顺序、人物关系；纸张、印章和打字效果服务证据。
- 材质：旧纸纹理淡于正文；原文片段保持清楚。时间/来源以稳定位置出现。
- 动作：整页→必要行→圈注/译文→相关事件或数据。每句最多一个主要标注，换重点时撤掉旧标注。
- 镜头：先让观众知道材料是谁、何时写的，再靠近需要读的行；裁切不得改变原意。
- 声音：低密度钢琴或无配乐；纸声只在纸张落定时，打字声不贯穿旁白。
- 变化：文件、人物关系、地点与时间线、表格和短引文；不要所有场景都塞进相同档案卡。
- 自检：材料是截图还是节选重排？二者标明。来源可核对吗？示意印章是否让观众误认真实机构背书？没有来源不能伪造档案。
- 边界：复原画面标教学/情境示意，不声称历史现场影像。现代财经文件也可用清洁纸张，不强迫做旧。
