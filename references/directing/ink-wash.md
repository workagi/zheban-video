# 水墨东方：导演规则

- 主体：以人物行动、山水空间或器物承载关系；诗意画面仍要交代本片要解释的对象。
- 光与材质：纸白是留白，浓墨在焦点；远景淡、主体实。墨晕不遮关键文字，朱砂只作必要强调。
- 动作：路径像行笔，干湿和速度有变化；先完成主体再读字。不要把所有信息都变成墨迹淡入。
- 镜头：沿空间或时间向相邻画面移动；长卷需维持方向与地标，切景时保留识别线索。
- 声音：克制拨弦/木音，旁白优先。史实语气由证据决定，风格不能添加虚构古语。
- 变化：人物近景、器物特写、地形关系、书写与局部圈点；按内容选择。
- 自检：脸和衣饰能区分人物吗？墨线是否连到正确对象？小字是否被纸纹和枝条干扰？临摹效果不可充当史料。
- 边界：当前山水/笔触是风格化代码绘制，不等于真实书法笔顺或历史人物肖像。
