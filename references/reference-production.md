# 参考片的底层制作方法

参照用户提供的《囚徒困境短片_源码》anim.js（SHA256 `a05d3346261b75f36d469df1ca84f446b69f27ffe6d495c54d932fecf7360bbd`）及 audio.py。用户要求借鉴分层光影、画面和节奏，且明确不调用 Claude。此文记录可迁移的方法；不把参考片文案、数据和固定秒数当成通用规则。

## 从观众需要出发

观众一次只能重点理解一个关系。每幕先写“要看懂什么”，再决定主体、证据怎样出现、何时揭晓、揭晓后留多久。质感来自可控的层次、明暗、物体结构与时间变化；只给模型“精致、电影感”的形容词没有定义这些决定。跨模型一致的部分应由共享实现承担。

## 固定绘制顺序

`engine/cinematic.js` 不包含主题、旁白或事实数字；稳定模式按以下顺序合成：

1. 远景：暗底、缓慢移动的暖色光场、低对比散景，运动速度与近景不同。
2. 主体：由镜头解释关系；金属用亮面/侧面/厚度/刻字和局部扫光建立体积。光效不能代替几何结构。
3. 近景：按深度分布的金尘、少量较大失焦光点，边缘漏光与暗角。
4. 字幕与常驻标题：在主要光效之后合成；避免文字被光晕、暗角或粒子削弱。
5. 统一颗粒与结尾淡出。

奖章厚度、透视压缩、刻字和反射运动改编自参考源码 medal；景深粒子、散景、漏光、暗角、颗粒的分层方式来自其全局绘制顺序。保留现有固定种子与逐帧时间驱动，不依赖实时播放时钟。2D 明暗面能满足本次目标，不增加 Three.js/HDRI 或额外服务。

## 节奏是事件之间的关系

`scene.staging` 的四种段落意图由 `engine/shots.json` 的 stagingProfiles 定义：

| 意图 | 用途 | 实现上的变化 |
|---|---|---|
| anticipate | 问题与悬念 | 低密度配乐，收敛背景；让观众注意问题 |
| explain | 展示过程 | 降低前景干扰，按解释步骤推进物体 |
| reveal | 结果揭晓 | 图解完成后出现结果强调、柔和光脉冲及可选重音 |
| resolve | 收束与余味 | 降低配乐密度，给结论阅读空间 |

这四种是可重复使用的意图，不要求每片按固定四段顺序排列。未填写 staging 时采用 explain；energy 可在0..1范围显式调节。文字、图形、事件、声音的具体时码仍由讲解决定，不把原片的120BPM和偶数秒切点强加给其他故事。

镜头的 computed.complete 由同一解析器推导：动画、揭晓强调和自动重音使用同一个完成时间。autoSfx 可以关闭；稳定模式不在每个切点机械叠加重击。上一轮复制的轻提示音跟随每一轮出现，排名的结果提示在柱子完成后出现；已经写了 impact 时不重复自动添加。配乐继续由现有合成器复用场景 energy，已有录音保留；改变画面不联网重新配音。

留白也是节奏。不要为通过动态扫描而持续晃动；机制解释要让完整关系停得住。分镜中记录铺垫、变化、揭晓、停留各自服务的理解任务，检查实际动画，而非只检查九张好看的关键帧。

## 借鉴与改正

原片11幕包含奖章、审讯室、收益矩阵、程序环、猜测、揭晓、复制、胜场、累计成绩、原则卡和结尾。这说明好片需要随论证变化的视觉语言。三种已注册镜头只是首批可复用单元，不能把所有选题压成同一个三页结构。未知关系在 custom 模式先做一个关键短镜头，通过后再收敛参数并注册。

原片 sTotals 使用 `40+(sc-250)/(504-250)*420` 放大柱高差；本 Skill 排名镜头共用零基线并按原值比例计算，不把这种未标注的截断尺度迁入通用图表。原片末句的普遍收益结论、四行程序等说法也不能随材质一并复用。事实另行核实，教学虚构数字明确标注。

参考源码目录未附旁白音频与字体文件，audio.py 生成配乐和音效。局部实渲使用本地项目字体补齐，不能据此称该目录独立重建了参考片的男声旁白。

## 一致性与证据边界

稳定模式固定 Canvas 读取后端，避免 Chrome 在多次读像素后自动切换绘制路径而产生抽帧差异；仍保留环境与素材锁。文字版面登记使用 Canvas 实际变换坐标，支持平移、缩放和右对齐，避免局部坐标被误判出屏。

制作默认由当前宿主模型与本地运行器完成，跨模型比较优先离线阅读用户提供的结果。当前用户明确要求不要调用 Claude 客户端；不因本机存在登录、命令或代理连接而继续调用。用户后来明确指定其他连接时，按其授权范围处理。接口返回 model ID 只是服务自报，不能独立验证实际提供商或订阅身份。

同一数据通过同一实现能减少材质、坐标、时序和数据关系的波动；文案判断、镜头选择、全新机制与风格仍需作品验证。自动QA不能证明达到参考片的美术与叙事水准。
